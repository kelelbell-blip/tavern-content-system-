# Tavern Production System

## What this is

This repository contains a set of scripts and skill files used for organizing and processing production content.

## Structure

The repository includes:
- scripts (automation tools)
- skill files (instruction templates for content workflows)

## How to use this

Scripts can be run locally depending on language (Python or JavaScript).

Example:
python script_name.py

## Purpose

The goal of this system is to take unstructured production materials and make them usable, consistent, and easy to maintain.

## How to extend

New scripts should be added to a scripts folder.
New skills should follow the same format as existing skill files.
